# 个人知识库与权限设计

## 目标

将现有只读“报告库”替换为个人知识库。知识条目默认仅创建者可见；创建者可在确认后向具体成员或内部团队授予只读访问。研究 Agent 只能取得调用用户已经获授权的片段，且内部资料仅作为上下文，不能写入正式评分、主题结论或报告版本。

## 边界与兼容

- `report_assets`、`report_versions` 和报告详情路由仍是正式主题报告的只读资产，不迁入知识库。
- 新增 `/api/knowledge` 资源和 `/knowledge` 页面；`/reports` 仍保留正式报告库入口，旧的可编辑报告库 UI 不再承担个人文件管理。
- 所有知识库写操作先创建 `pending_operations` 预览。确认令牌绑定用户、操作、目标条目版本和过期时间；写 API 必须携带幂等键，客户端绝不自动重放。
- 服务契约提升到 `2026-08-18.v18`，启动器、契约导出和运行手册同步更新。

## 持久化模型

`knowledge_items` 保存稳定条目 ID、创建者、种类、标题、当前版本、状态、主题/标签和软删除时间。`knowledge_item_versions` 是不可变版本链，保存内容哈希、原始文件名、MIME 类型、受控相对路径、文本提取状态和创建时间。`knowledge_folders` 和 `knowledge_folder_entries` 表示用户拥有的文件夹及条目位置；文件夹移动绝不改变条目所有权。`knowledge_shares` 是可撤销的成员或团队主体授权记录。`document_chunks` 绑定条目版本，保存文本、顺序、页码/字符位置和来源类型。

物理上传仅写入由 `KNOWLEDGE_FILES_DIR` 指定（默认 `data/knowledge-files`）的受控目录。客户端文件名只能作为元数据；写入路径由条目和版本 ID 构造，不接受客户端路径。每个版本都计算 SHA-256；软删除保留文件和版本，恢复仅恢复最新未丢失版本。缺失文件使条目处于 `missing_file`，不得伪造可检索内容。

## 权限与检索

权限判定是单一的 `KnowledgePermissions.can_read`：所有者、存在的成员共享或存在的团队共享可读取；只有所有者可管理共享、移动、软删除或恢复。对 API 列表、单条读取、全文检索、分块检索以及研究上下文使用同一个 SQL 权限谓词，并在计算相关性、标题投影、计数和 token 预算之前执行。拒绝条目不会以 ID、标题、总数、排序位置或预算消耗暴露。

检索仅搜索活动条目的当前版本；按照主题匹配、更新时间、类型和确定性全文匹配排序。返回的每个片段都包含 `knowledge_item_id`、版本、来源类型、页码或字符区间、内部资料标记和可访问的显示标题。撤销共享在同一短事务提交后，后续读取和上下文构造立即失效。

## 解析与上下文

条目可由笔记、会议材料、ETF 产品资料、上传文件、对话摘录或保存引用创建。文本、Markdown、JSON、HTML、PDF 和 DOCX 进入受限解析器；不支持的 MIME 类型记录失败状态且不建立片段。片段使用固定字符窗口与重叠，PDF 页码和其他文档的字符范围均持久化。解析只处理冻结版本，不修改原文件。

研究运行在获取基础正式资产后，通过 `KnowledgeRetrieval` 以当前用户和主题取得已授权片段。`build_research_context` 接收的知识层只能含检索器产物并标注 `internal_material`；层级仍为正式主题资产、已核验证据、冻结 ETF 快照、内部知识库、记忆/用户观点、待验证线索。评分、结论和报告写入路径不接收知识库片段。

## 前端方案 C

`/knowledge` 显示“我的文件夹”和智能集合（最近更新、与当前主题相关、已共享、已删除），默认卡片清晰显示“仅自己可见”。搜索、筛选和列表均依赖授权 API。共享、移动、删除和恢复从预览弹窗开始：展示动作、目标、受影响可见性或文件夹及当前版本；仅在用户点击确认后调用确认端点。网络失败仅显示错误，绝不重放写请求。

## 备份与恢复

备份创建 SQLite 一致副本和知识文件目录快照，并保存数据库/文件清单及 SHA-256。恢复仍要求停止 API、精确 `--confirm-target`，并在独立目标目录恢复数据库和文件，再验证每个活动版本的路径、哈希、权限记录和片段数。恢复过程不得覆盖未确认目标或重写源备份。

## 验证

单测覆盖版本、软删除/恢复、路径逃逸、成员/团队共享、撤销、权限先于检索、页码/位置、上下文信任边界和备份恢复。API 契约测试覆盖 v18 与确认令牌。Playwright 覆盖默认私有可见性和共享/移动/删除的预览确认流程。交付前运行全量 pytest、前端 lint、知识库 E2E 和独立恢复演练。
